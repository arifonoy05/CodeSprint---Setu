# RCA-1085 — Schedule regenerated on restructure wiped paid history

**Severity:** Medium
**Module:** Repayment Schedule
**Raised:** 2025-01-16
**Closed:** 2025-01-24

## Summary
Restructuring a loan deleted schedule rows that had already been partially paid, orphaning the
`repayment` rows that referenced them.

## Root cause
`rebuildSchedule()` deletes rows `WHERE paid = false`. A row that has received a partial payment
still has `paid = false`, so it is deleted, while `repayment.schedule_id` still points at it. There
is no foreign key action defined for that reference.

## Preventive action
**Open.** Needs a definition of what restructuring means for partially paid installments.
