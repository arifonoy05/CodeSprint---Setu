# RCA-1063 — Partial disbursement exceeded sanctioned principal

**Severity:** Critical
**Module:** Loan Disbursement
**Raised:** 2024-08-07
**Closed:** 2024-08-15

## Summary
A construction loan received tranches totalling 12% more than the sanctioned principal.

## What happened
Two officers released tranches for the same loan within the same minute from different branches.
Each read the released-to-date total before either had written its own row.

## Root cause
`disburseTranche()` reads `totalReleased()` and then writes, with no lock and no transaction
covering both. The check-then-act sequence is a race. `SINGLE_BORROWER_LIMIT` in
`eligibility_rules` has the same shape and the same exposure.

## Resolution
Excess recovered from the borrower. No code change made.

## Preventive action
**Open.** Requires either row-level locking on the loan or a database constraint on cumulative
tranche value.
